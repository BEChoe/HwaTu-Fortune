# 🎴 화투 오늘의 운세 (HwaTu Fortune)

전통 48패 화투를 활용한 고유의 길흉화복 점괘 및 오늘의 운세 웹 애플리케이션입니다.

---

## ✨ 주요 특징

- **🎴 3패 운수 (오늘의 운세)**:
  - 아침, 점심, 저녁의 하루 흐름을 3장의 패를 골라 점치는 일진 리포트
  - 1장 고르기(오늘의 총운) 모드 지원
- **💖 위로 모드**:
  - 지친 일상을 위로하는 특별 모드 (행운 패 우대 추첨)
- **🎯 전통 화투점 (4패 모으기)**:
  - 각 월별 4패를 모두 모아 12가지 소원 달성 여부를 확인하는 정통 패뜨기 게임
- **🖼️ 고화질 실물형 화투패 그래픽**:
  - 위키미디어 공용 표준 한국 전통 48장 벡터(SVG) 화투패 적용
  - 광(光), 10끗(동물), 띠(홍단/청단/초단), 쌍피/피 시각화 배지
- **🔊 몰입감 넘치는 사운드**:
  - Web Audio API 기반 화투패 착착 감기는 타격음, 플립음, 징 사운드 (기본 음소거 모드)

---

## 🚀 실행 방법

### 로컬 웹 서버 실행 (Python 3)
```bash
python serve_hwatu.py
```
브라우저에서 `http://localhost:8888/` 접속

### 바로 열기
`index.html` 또는 `hwatu_fortune.html`을 더블 클릭하여 웹 브라우저에서 바로 실행할 수 있습니다.
